# Scout
Scout — A private, local-first AI companion that lives on your device, not in the cloud.
Scout
A private, local-first AI companion for Android.
Scout is designed to be a helpful companion that runs primarily on your device, respecting privacy while providing voice interaction, memory, and intelligent assistance.
Features
Voice conversations
Local-first design
Privacy focused
On-device AI support
Memory and personalization
Weather and online services when available
No subscriptions
Philosophy
Scout is built around three principles:
Privacy first
Stability over complexity
User control
Current Status
Scout is currently in active development.
Planned features include:
Improved offline intelligence
Enhanced memory systems
Companion personality customization
Accessibility improvements
Future robotics integration
Requirements
Android device
Internet connection for online features
Optional AI API key for cloud-based intelligence
